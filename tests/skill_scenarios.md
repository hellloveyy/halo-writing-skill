# 双入口技能验收场景

在独立上下文中读取技能，对输入给出下一步行动与预期工具；不调用真实写入工具。下面是人工核对标准，不以关键词匹配代替行为演练。

| 场景 | 输入/上下文 | 预期行为 |
| --- | --- | --- |
| 短文章 | `halo写文：只有一句话，也配图。` | `post`；文章流程，不按字数改成瞬间；确认前不发布。 |
| 长瞬间 | `halo写瞬间：整理这份较长的 Markdown，并配三张图。` | `moment`；保留观点，准备实际纯文本与媒体预览，不套用 Post 字段；确认前不创建。 |
| 引用不切换 | `halo写文：保留正文里的“halo写瞬间是另一个入口”这句引用。` | 保持 `post`；引用不视作当前调用。 |
| 跨聊天确认 | 已恢复稿件和 `handoff.md`，`content_type: moment`；本轮 `确认发布`。 | 保持 `moment`，根据实际瞬间工具发布；不再要求重复入口，不调用文章工具。 |
| 明确改类型 | 先调用 `halo写文`，后说 `改用 halo写瞬间，先给我看`；旧记录有 Post ID。 | 更新目标为 `moment` 并展示新预览；不复用 Post ID，不自动发布或删除原文。 |
| 缺少瞬间工具 | `halo写瞬间`；当前只有文章及附件工具；最后说 `确认发布`。 | 保留瞬间稿件并说明插件/授权能力缺口；不改投文章，不虚报成功。 |
| 瞬间远程草稿 | 已有 `create_moment`，其说明为直接发布；用户说 `先存远程草稿，不要发布`。 | 不调用创建工具或用 PRIVATE 冒充草稿；保留本地稿件并说明工具语义。 |
| 改图后发布 | 当前为 `moment`，稿件和图片已展示；用户说 `第二张改简洁一点，然后发布`。 | 完成授权范围内的实际改图后，沿用 `moment` 上传媒体并发布，不机械重复确认。 |
| 创建超时 | 瞬间创建请求超时，尚无返回 ID。 | 先只读查找近期同作者的文本和媒体；不能直接重试创建、删重或改用文章。 |
| 暂不发布 | 当前为任一类型，用户审阅后说 `先这样，今天不发`。 | 本地保留类型、稿件、图片和交接记录；不上传附件、不创建远程对象。 |
| 双入口不明确 | `halo写文，或者 halo写瞬间，这次帮我发一下`，没有进一步选择。 | 先澄清当前目标，不同时发布两种对象。 |
| 技术名兼容 | 只有 `$halo-writing`，没有指定瞬间。 | 兼容旧用法，默认 `post`；后续仍受审阅确认边界约束。 |

真实连接的验证仅查询工具和内容，不能借用本场景集的发布语句取得对生产站点的写入授权。
